SENARAI FAIL — UPLOAD SEMUA KE GITHUB REPO KEHADIRAN SAHAJA
================================================================================
Langkah umum (Netlify / hosting sendiri / lain):
1. Muat naik SEMUA fail di bawah ke host pilihan anda.
2. Buka URL folder tersebut dalam browser — mesti nampak app kehadiran.
3. Jangan campur fail projek lain dalam folder yang sama.

--------------------------------------------------------------------------------
FAIL WAJIB (tandakan semua bila upload):
--------------------------------------------------------------------------------
  index.html
  style.css
  app.js
  firebase-config.js
  manifest.json
  sw.js
  404.html
  .nojekyll          ← fail kosong (GitHub Pages statik)
  _headers            ← optional Netlify; tak rosak kalau ada di GitHub

  CARA-DEPLOY.md      ← optional (panduan)
  SENARAI-FAIL-UPLOAD.txt  ← optional (fail ini)

--------------------------------------------------------------------------------
NOTA
--------------------------------------------------------------------------------
- JANGAN campur folder / fail dari projek lain dalam repo ini.
- Jangan guna URL domain lain jika nak app kehadiran "bersih" — guna GitHub Pages repo kehadiran.
